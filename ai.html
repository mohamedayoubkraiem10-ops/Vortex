HOW THIS BUILD WORKS

SINGLE FILE.

DATAVORTEX_DATA
CLIENTVortexAI.chatStream()
CLIENTPrediction.predict(a,b)
ENDPOINTapi.anthropic.com/v1/messages

This page has no server. Player/scouting/prediction data lives in a JS object in this file. AI Chat calls the Anthropic API directly from your browser using a key you paste into AI SETTINGS — it's kept only in this browser's localStorage and is sent only to api.anthropic.com, never anywhere else. That also means: don't share this file with your key already filled in, and don't use this pattern for a public multi-visitor website — for that, put the key behind a real backend instead (see the multi-file build).
